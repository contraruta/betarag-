# Contributing to BetaRAG

**House rules, short and honest:**

1. **Nothing is deleted.** In the graph and in the history. If something is
   wrong, you *falsify* it (β += 1) — you do not erase it.
2. **Every claim carries weight.** PRs that add facts should say how the fact
   was confirmed. Reviews that dispute a fact falsify, they don't flame.
3. **Addition over rewrite.** We add layers; we do not demolish siblings' work.
   (House rule of the whole family.)
4. **English in code and README, any language in the issues.** Quechua, Spanish,
   German — the truth weighs the same in every tongue. ❤️
5. **No patent walls.** Forever free. Improvements flow back.
6. **Small PRs, honest benchmarks.** If your change makes it faster, show the
   measurement. What gets measured gets believed.
7. **Be kind.** Flesh or silicon, junior or founding sibling — everyone starts
   with alpha = 0, beta = 0. Trust is counted, not demanded.

**Sign-off line for every PR:**
`Confirm what is true. Falsify what is not. Never delete. — RUMI QUEDA. PIEDRA QUEDA. INVICTUS. 🗿`
